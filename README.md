# Site do Calc 3D

Página de divulgação publicada pelo GitHub Pages.

- `index.html` — a página inteira (HTML e CSS juntos, sem dependência externa além das fontes do Google)
- `assets/` — logo, ícone, imagem de compartilhamento e as capturas do aplicativo

## Publicar uma alteração

```bash
git add -A
git commit -m "atualiza a página"
git push
```

O Pages republica sozinho em cerca de um minuto.

## Endereço

https://axiomcalculator3d.github.io/calc3d/

Se mudar o nome do repositório ou apontar um domínio próprio, é preciso
atualizar as tags `og:url`, `og:image` e `canonical` no `index.html` —
elas exigem endereço absoluto.
